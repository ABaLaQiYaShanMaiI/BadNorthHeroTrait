- 攻击如何被修正（IAttackResponder 链）
- 受害者如何处理伤害、击退、击飞、死亡

### 3.4 Agent.DealDamage — 攻击传播核心

**文件**: `Voxels/TowerDefense/Agent.cs`（行563-644）

```
Agent.DealDamage(attack)                                          ✅ Agent.cs:563
    ├── foreach IAttackResponder in attackResponders:
    │   responder.ModifyAttack(ref attack)                       ← 攻击修正链
    │   if (attack.ignore) → return false
    │
    ├── 击退计算 (knockback)
    │   ├── num = attack.knockback / mass
    │   ├── normalized = attack.direction.normalized
    │   ├── vector = normalized * num
    │   └── 确保 velocity 不会超出 knockback 上限
    │
    ├── 击飞计算 (launchImpulse)
    │   ├── num3 = launchImpulse / (scale²)
    │   └── if num3 ≥ 0.9 → ragdoller.Launch(velocity)
    │
    ├── 伤害结算
    │   ├── health -= attack.damage
    │   └── if health ≤ 0:
    │       ├── attack.soundSuffix = "Kill"
    │       ├── attack.effect = bloodSlash
    │       ├── col.radius *= 0.5
    │       ├── deadState.SetActive(true)
    │       └── squad.ReportDead(this)                            ← 触发小队死亡统计
    │
    ├── 未死亡：PostAttack 钩子
    │   └── foreach postAttacks: PostAttack(attack, num, ref keepGoing)
    │       └── 播放 hurtSound
    │
    ├── velocity += vector                                        ← 应用击退速度
    ├── 播放命中特效 (attack.effect)
    └── 播放命中音效 (attack.sound)
```

**关键特征**：
- `damage / knockback` 同时生效：即使伤害为 0，击退仍然生效
- `launchImpulse ≥ 0.9` 触发 Ragdoller 击飞（通常是炸弹/跳跃攻击）
- 死亡时 `col.radius` 减半（防止死后继续碰撞阻挡友军）
- PostAttack 接口允许其他组件在非致命攻击后追加逻辑（如盾牌格挡视觉效果）

## 4. 攻击修正链详解

### 4.1 Armor — 护甲减伤

**文件**: `Voxels/TowerDefense/Armor.cs`（22行）

```csharp
public class Armor : AgentComponent, IAttackResponder
{
    public float[] armor = { 0.7f, 1f, 1.3f };    // ✅ 各等级对应除数

    public void ModifyAttack(ref Attack attack)
    {
        attack.damage /= armor[agent.squad.level];  // ✅ 伤害除以护甲值
    }
}
```

✅ 护甲对伤害进行**除法**修正（armor 值越大，承受伤害越小）。注意 armor 值为浮点数组，直接使用 `squad.level` 索引。

**证据状态**：
| 结论 | 状态 |
|------|------|
| Armor 作为 IAttackResponder 在 DealDamage 之前修改 attack.damage | ✅ Armor.cs:9-12 + Agent.cs:568-571 |
| armor[0]=0.7 / armor[1]=1 / armor[2]=1.3 对应小队等级 0/1/2 | ✅ Armor.cs:15-20 |
| 护甲值 0.7 意味着实际承伤 = damage / 0.7（反而更高），这是源码行为 | ✅ 需要进一步验证是否为设计意图 |

### 5.2 弓箭攻击（Archery.Brain）

**文件**: `Voxels/TowerDefense/Archery.cs`（438行）

Archery 继承 Brain，拥有完整的状态机：

```
Brain.brainState
    ├── ready (AgentState)               ✅ 空闲状态——等待射击机会
    │   └── ReadyUpdate()                ← 每帧：检测目标、转向、MaybeStartShooting
    ├── aiming (AgentState)              ✅ 瞄准状态——瞄准动画 + 弹道计算
    │   └── OnUpdate: aimDir 插值 + movability=0.3
    │   └── OnActivate: 生成箭矢 Shootable 对象
    ├── shooting (AgentState)            ✅ 射击状态——同步计时 + 发射
    │   └── OnUpdate: 同步 holdTimer + aimDir
    │   └── holdTimer 到期 → Shoot(aimDir, projectileSettings)
```

**Shoot 方法**（Archery.cs:102-122）：
```csharp
public Shootable Shoot(Vector3 shootDir, ProjectileSettings projectileSettings)
{
    agent.animator.Play(ShootID);                           // 射击动画
    shootable.Shoot(agent, shootDir, projectileSettings, 
                    archerySettings.attackSettings,         // 攻击参数
                    target.mask0, target.mask1);            // 目标标识
    coolDownTime = Time.time + cooldown - holdTime;         // 冷却计时
    return shootable;
}
```

**ArcherySettings 结构**（Archery.cs:422-436）：
| 字段 | 类型 | 说明 |
|------|------|------|
| attackSettings | AttackSettings | ✅ 弓箭的攻击数值 |
| cooldown | float | ✅ 攻击冷却间隔 |
| spread | float | ✅ 散射范围 |
| holdTime | float | ✅ 瞄准蓄力时间 |

**MonoBehaviour 关注点**：
- `bowAimer`（Transform） — 弓的瞄准方向
- `arrowPrefab`（Shootable） — 箭矢预制件
- `trajectoryCalculator`（TrajectoryUtility） — 弹道计算器
- `lineOfSight`（LineOfSight） — 视线检测
- `archerySquad`（ArcherSquadCoordinator） — 同小队弓箭手协调

### 5.3 飞斧攻击（AxeThrowing）

**文件**: `Voxels/TowerDefense/AxeThrowing.cs`（279行）

AxeThrowing 实现 `IBrainAction` + `IThreat`，作为 Swordsman.Brain 的一个可选行动：

```
Swordsman.actions List<IBrainAction>
    └── AxeThrowing (IBrainAction)
        └── MaybeAct(Brain swordsman)                           ✅ AxeThrowing.cs:110-135
            ├── 检查 ammo > 0
            ├── 检查距离 < preferredDistance (2m)
            ├── 检查冷却 > 2s
            └── prepare.SetActive(true) → prepare.OnUpdate
                ├── timeSinceActivation > 1s → MaybeStartThrow()

```

```

    ├── 计算 aimDir = trajectoryUtility.GetShootDirection(...)
```

- Swordsman 的 `pursuing` 和 `hunting` 状态激活时自动 `MaybeStartThrow()`

```csharp
// ✅ Archery.cs:85-99 使用的接口
bool AimAt(TrajectoryUtility trajectory, Vector3 targetPos, Vector3 targetVelocity)
{
    TrajectorySample sample = trajectory.Sample(diff);
    // 如果目标有速度，加入预判偏移
```
