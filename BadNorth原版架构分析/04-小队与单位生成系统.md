# 04 · 小队与单位生成系统

> **本文档目标**：解析英雄部署到岛屿后，小队（EnglishSquad）和单位（Agent）的生成流程——从 MonoHero 视觉生成 → Squad 容器 → Agent 实例化 → SquadTemplate 应用。

---

## 1. 系统目标

小队与单位生成系统解决：
- 英雄数据（HeroDefinition）如何对应到 3D 视觉表现（MonoHero）
- 英雄部署后如何创建 EnglishSquad 实例
- 小队如何按 SquadTemplate 生成一组 Agent（含标准旗手 + 士兵）
- 小队人数（maxCount）如何由升级（SquadSizeUpgrade）动态调整
- 升级的 AbilityPrefab 如何在部署时挂载到小队

**FillRoutine 协程详解**：
```csharp
public IEnumerator FillRoutine(NavSpot navSpot)         // ✅ EnglishSquad.cs:227
{
    SquadFormation formation = new SquadFormation(maxCount, navSpot);
    for (int i = 0; i < maxCount; i++)
    {
        if (i >= agents.Count)
        {
            Vector3 formPos = formation.Get(i);            // ← 阵型位置计算
            Vector3 offset = formPos * minionPrefab.radius * 2f * 0.6f;
            offset += Random.insideUnitSphere.SetY(0) * minionPrefab.radius * 1.2f;
            NavPos spawnPos = navSpot.navPos;
            spawnPos.pos += offset;
            CreateAgent(minionPrefab, spawnPos);           // ← 调用 Squad.CreateAgent
        }
        yield return null;                                  // ← 逐帧生成（避免卡顿）
    }
    BroadcastChange();
}
```

public class TemplateUpgrade : UpgradeComponent
{

    }

✅ 在英雄部署时通过 UpgradeComponent 的生命周期自动调用

#### SquadSizeUpgrade
**文件**: `Upgrades/SquadSizeUpgrade.cs`（36行）
```csharp
public class SquadSizeUpgrade : HeroUpgradeDefinition, MonoHero.IRankModifier
{
    public int[] sizeAtLevel = { 12, 16 };                 // ✅ 各等级对应人数

    public override void OnAppliedToSquad(EnglishSquad squad, int upgradeLevel)
    {
        squad.maxCount += sizeAtLevel[upgradeLevel] - 9;   // ✅ 动态调整最大人数
    }
}
```
