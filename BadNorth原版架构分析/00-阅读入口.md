# Bad North 原版架构分析 · 阅读入口

> **按你的需求，选择最快的阅读路径。**

## 📌 本目录定位

本目录（`BadNorth原版架构分析/`）是**原版反编译 C# 源码的专题分析文档集合**。

- **讨论范围**：原版游戏的各子系统架构、核心类关系、数据流与生命周期
- **不讨论**：Mod 实现、BepInEx 框架、特质模组代码
- **源码依据**：`《BadNorth原版》Assembly-CSharp(源文件)/` 中的反编译代码
- **Mod 相关**：请参阅仓库根目录的 `BadNorth特质与Mod架构完全解析.md`

> 每个分析文档都遵循统一模板，并标注证据等级。详见 [文档编写规范](#文档编写规范)。

## 文档编写规范

每个专题文档固定包含以下章节：

1. **系统目标** — 这个子系统解决什么问题
2. **入口类** — 从哪个类/方法开始阅读
3. **核心类** — 该子系统最重要的类（含类路径和行数）
4. **数据流** — 数据从哪里来、经过谁、到哪里去
5. **生命周期** — 何时创建、何时更新、何时销毁
6. **与其他系统的依赖** — 上下游关系
7. **证据状态** — 已确认 / 高概率推断 / 未确认（必须标注）
8. **关键风险/未解点** — 当前分析的盲区

## 证据标注系统

| 标记 | 含义 |
|------|------|
| ✅ **已确认** | 直接从源码中可验证的结论（附类.方法.行号） |
| 🟡 **高概率推断** | 由多处调用关系推断，但未完整跑通完整链路 |
| ❓ **未确认** | 当前未找到关键调用点或初始化时机，待后续验证 |
