## 3. 核心类

### 3.1 AgentState — 层次化状态节点

**文件**: `Voxels/TowerDefense/AgentState.cs`（472行）

AgentState 是 BadNorth 运行时行为系统的基石。它不是传统的 FSM（有限状态机），而是一个**层次化排他状态树**：

```csharp
public class AgentState
{
    public string name;                        // ✅ 状态名（如"Dead"/"Alive"/"Brain"）
    public bool active;                        // ✅ 当前是否激活
    public bool exclusive;                     // ✅ 是否为互斥状态（同层级同时只能一个 active）
    public AgentState parent;                  // ✅ 父状态（null 为根）
    public List<AgentState> children;          // ✅ 子状态列表
    public readonly AgentStateRoot stateRoot;  // ✅ 所属的状态树根

    // 回调
    public Action OnActivate;    // ✅ 状态激活时触发
    public Action OnDeactivate;  // ✅ 状态停用时触发
    public Action OnUpdate;      // ✅ 每帧 Update（仅 active 时执行）
    public Action OnEmpty;       // ✅ 所有互斥子状态都停用时触发
}
```

**核心机制——`SetActive` 内部逻辑**（AgentState.cs:289-366）：

```
SetActive(newActive)
    ├── 若 newActive == _active → return
    ├── SetActiveInternal(newActive)
    │   ├── 若激活 (newActive=true):
    │   │   ├── 排他性处理：遍历 siblings，停用其他 exclusive 状态  ← 同名互斥
    │   │   ├── 级联激活：parent.SetActive(true)                    ← 自动激活父状态
    │   │   ├── _active = true
    │   │   ├── OnActivate()                                        ← 触发激活回调
    │   │   └── OnChange(true)
    │   └── 若停用 (newActive=false):
    │       ├── 级联停用：遍历 children，全部 SetActiveInternal(false)
    │       ├── _active = false
    │       ├── OnDeactivate()                                      ← 触发停用回调
    │       └── OnChange(false)
    ├── stateRoot.SetDirty()                                         ← 标记脏，需要重建 activeStates 列表
    ├── 激活后：MaybeEmpty()（若无互斥子状态激活，触发 OnEmpty）
    └── 停用后：parent.MaybeEmpty()（父状态检查 OnEmpty）
```

**关键概念**：

| 概念 | 说明 | 典型例子 |
|------|------|----------|
| **exclusive** | 同父级下同时只有一个 exclusive 状态可以 active | deadState / aliveState 互斥 |
| **级联激活** | 激活子状态会强制激活父状态 | shooting 激活 → aiming 激活 → brainState 激活 |
| **级联停用** | 停用父状态会递归停用所有子状态 | brainState 停用 → actingState 停用 → ... |
| **OnEmpty** | 当所有互斥子状态都停用时触发 | exclusives.OnEmpty → brainState 激活（空闲状态回退） |
| **OnUpdate** | 仅 active 状态会在 AgentStateRoot.Update 中执行 | 用于每帧行为逻辑（如射击瞄准更新） |

**Agent 核心状态树结构**（Agent.cs:385-494）：

```
Agent.rootState (AgentState, exclusive=false)
    ├── navigationState (non-exclusive, always active)        ✅ 导航层
    │   └── groundedState (exclusive)                         ✅ 站在岛上时 active
    ├── lifeState (non-exclusive)
    │   ├── aliveState (exclusive)                            ✅ 默认 active
    │   └── deadState (exclusive)                             ✅ 死亡时 active
    ├── spawned (non-exclusive, 生成后才 active)              ✅ 生成完成标志
    ├── moveAnimateState (non-exclusive)                       ✅ 允许移动动画
    ├── aliveAndGrounded = aliveState ∧ groundedState ∧ spawned  ✅ 组合状态
    │   └── exclusives (non-exclusive)                        ← Brain 挂载点
    │       ├── [Brain 子状态]
    │       │   ├── brainState (exclusive)                    ← 空闲/AI 决策
    │       │   ├── actingState (exclusive)                   ← 执行动作中
    │       │   ├── triflow (non-exclusive)                   ← TriFlow 导航
    │       │   └── ready/aiming/shooting etc.                ← 兵种特定子状态
    │       ├── [Death 状态]
    │       ├── [Stun 状态]
    │       └── [其他组件状态]
```

✅ `aliveAndGrounded` 是 `aliveState.active ∧ groundedState.active ∧ spawned.active` 的合成状态，由 `AliveAndGrounded(bool)` 方法维护（Agent.cs:686-688）。

### 3.2 AgentStateRoot — 状态树调度器

**文件**: `Voxels/TowerDefense/AgentStateRoot.cs`（145行）

AgentStateRoot 管理一个 Agent 的所有状态，提供每帧的 Update 调度：

```
AgentStateRoot.Update()                            ✅ AgentStateRoot.cs:51-107
    ├── 若 dirty:
    │   ├── activeStates.Clear()
    │   └── DFS 遍历 rootState 树：
    │       └── 收集所有 active ∧ hasUpdate 的状态 → activeStates 列表
    │       └── dirty = false
    ├── 遍历 activeStates：
    │   └── agentState.DirectUpdate()              ← 执行 OnUpdate 回调
    │   └── 若 dirty 被重新置位（更新期间状态变更）：
    │       └── 重建 activeStates 列表（从当前位置继续）
```

**核心细节**：
- `dirty` 标记：任何 AgentState 的激活/停用都会调用 `stateRoot.SetDirty()`，触发重建
- `activeStates` 是展平列表：DFS 收集有 `OnUpdate` 监听且 active 的状态
- 使用静态 `Stack<AgentState>` 作为 DFS 栈（避免每帧分配）
- `capacity = 4` 默认容量（AgentStateRoot.cs:12）

### 3.3 Brain — AI 基类

**文件**: `Voxels/TowerDefense/Brain.cs`（172行）

Brain 是挂载在 Agent 上的 MonoBehaviour（AgentComponent 子类），负责：

```
Brain.Setup()                                          ✅ Brain.cs:80-104
    ├── brainState = new AgentState("Brain", exclusives, true, true)     ← 挂到 exclusives 下
    ├── actingState = new AgentState("Acting", exclusives, false, true)  ← 行动中（互斥）
    ├── 收集所有子组件的 IAgentOrder → orderList
    ├── 收集所有子组件的 IBrainAction → actions
    ├── exclusives.OnEmpty += brainState.SetActiveTrue   ← 所有 exclusive 状态停用时回退到 Brain
    ├── actingState.OnEmpty += brainState.SetActiveTrue  ← 行动结束回退到 Brain
    ├── brainState.OnUpdate += PickNewOrder              ← 每帧选择活跃 order
    ├── triflow = new AgentState("TriFlow", aliveAndGrounded, true, false)
    │   └── OnUpdate: agent.faction.presenceObj.AddPending(triFlowData)  ← 注册到导航流
    └── aliveAndGrounded.OnActivate += triflow.SetActiveTrue
```

**关键字段**：
| 字段 | 类型 | 说明 |
|------|------|------|
| actions | List\<IBrainAction\> | ✅ 可选行动列表（如 AxeThrowing、JumpAttack） |
| orderList | List\<IAgentOrder\> | ✅ 移动指令列表 |
| order | IAgentOrder | ✅ 当前选中的 order |
| orderMono | MonoBehaviour | ✅ order 的 MonoBehaviour 引用 |
| brainState | AgentState | ✅ AI 空闲状态（挂载到 exclusives） |
| actingState | AgentState | ✅ 执行动作状态（互斥） |
| triflow | AgentState | ✅ TriFlow 导航流注册 |

**MaybeAct 方法**（Brain.cs:39-49）：
```csharp
public bool MaybeAct() {
    for (int i = 0; i < actions.Count; i++) {
        if (actions[i].MaybeAct(this))    // ← 依次尝试 IBrainAction
            return true;
    }
    return false;
}
```

✅ MaybeAct 按 actions 列表顺序依次尝试，第一个返回 true 的 IBrainAction 获得执行权。

**PickNewOrder 方法**（Brain.cs:58-72）：
```csharp
public void PickNewOrder() {
    if (order == null || !order.WantsControl() || order == nullOrder) {
        foreach (IAgentOrder agentOrder in orderList) {
            if (agentOrder.WantsControl()) {
                order = agentOrder;
                orderMono = (order as MonoBehaviour);
                break;
            }
        }
    }
}
```

✅ PickNewOrder 在 brainState.OnUpdate 中每帧调用。NullOrder 永远返回 `WantsControl() = true`，作为兜底。

### 4.1 Archery（弓箭手）— 远程攻击状态机

**文件**: `Voxels/TowerDefense/Archery.cs`（438行）

```
Brain.brainState (exclusive, 挂到 exclusives)
    ├── ready (exclusive)                          ✅ 空闲——等待目标进入视线
    │   └── ReadyUpdate()
    │       ├── hz16: MaybeStartShooting()         ← 检查射击条件
    │       │   ├── coolDownTime > Time.time → false（冷却中）
    │       │   ├── enemyDist < 0.3 → false（太近）
    │       │   ├── (English) dist 检查 + 旗手优先
    │       │   ├── target = lineOfSight.target
    │       │   └── shooting.SetActive(true)
    │       ├── hz8: MaybeAct()                    ← 尝试 IBrainAction
    │       ├── English: ApplyWalk/ApplyOrder + 朝向敌人
    │       └── Viking: 撤退/保持距离/ApplyOrder
    │
    ├── aiming (exclusive, ready 的子状态)         ✅ 瞄准——蓄力 + 弹道计算
    │   ├── OnActivate:
    │   │   ├── aimDir = bowAimer.forward
    │   │   ├── animator.SetBool("Aim", true)
    │   │   ├── spawnArrowOnAim → 生成箭矢预制件
    │   │   └── PostEvent(drawSound)
    │   └── OnUpdate:
    │       ├── movability = 0.3                   ← 减速瞄准
    │       ├── aimDir = Lerp(aimDir, aimDirTarget, dt*8)
    │       └── LookInDirection(aimDirTarget, 720, 0)
    │
    └── shooting (exclusive, aiming 的子状态)     ✅ 射击——同步 holdTimer + 发射
        ├── OnActivate: holdTimer = Time.time + holdTime
        └── OnUpdate:
            ├── 视线检测：target 更新
            ├── AimAt(target.agent.chestPos, targetVelocity)
            ├── 同小队同步 holdTimer（弓箭手齐射）
            ├── holdTimer = Max(holdTimer, timeSinceActivation + 0.5f)
            └── holdTimer 到期 → Shoot(aimDir, projectileSettings)
                ├── animator.Play(ShootID)
                ├── PostEvent(shootSound)
                ├── shootable.Shoot(agent, shootDir, ...)
                └── shooting.SetActive(false)
```

**状态机回退链**（Archery.cs:205-211）：
```
brainState.OnEmpty     → ready.SetActiveTrue       ← 所有子状态停用后回到 ready
aiming.OnEmpty         → aiming.SetActiveFalse     ← 瞄准被中断
actingState.OnDeactivate → ready.SetActiveTrue     ← 行动结束
```

✅ 弓箭手的状态机设计保证了：冷却中不动 → 瞄准时减速 → 同一小队弓箭手齐射高度同步。
