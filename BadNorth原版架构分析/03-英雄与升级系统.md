# 03 · 英雄与升级系统

> **本文档目标**：解析英雄数据模型与升级购买流程——从 HeroDefinition → HeroUpgradeDefinition 虚方法 → 升级槽绑定 → 存档序列化。

---

## 1. 系统目标

英雄系统解决：
- 管理英雄的 4 个升级槽（Class/Item/Skill/Trait）
- 提供金币驱动的升级购买流程
- 通过虚方法让每个升级定义自己的行为（OnPurchased、OnAppliedToSquad 等）
- 支持折扣、疲劳度、死亡等运行时状态
- 通过 SerializableHeroUpgrade 连接到存档系统

### 3.5 购买流程详解

```
Player clicks upgrade button
    ↓
HeroDefinition.TryPurchase(upgradeDef, level, ref coinBank)
    ↓
根据 upgradeDef.typeEnum 分发：
    Item → TryPurchase(ref itemUpgrade, ...)
    Class → TryPurchase(ref classUpgrade, ...)
    Skill → TryPurchase(ref skillUpgrade, ...)
    Consumable → TryPurchaseConsumable(...)
    ↓
TryPurchase(ref slot, def, level, ref coinBank) HeroDefinition.cs:341-353
    ├── 计算成本：GetUpgradeCost(def, level, out discounted)
    │     └── def.GetLevelCost(level) × (1 - discount) if discountType matches
    ├── 检查 coinBank >= 成本
    ├── AddUpgrade(ref slot, def, level)
    │     ├── 设置 slot.level = level
    │     ├── def.OnPurchased(this, level)         ← 虚方法钩子 1 ✅ HeroDefinition.cs:400
    │     ├── def.OnAttachedToHero(this, level)    ← 虚方法钩子 2 ✅ HeroDefinition.cs:401
    │     ├── def.OnAttachedToMonoHero(monoHero, level) ← 虚方法钩子 3 ✅ HeroDefinition.cs:402-405
    │     └── RefreshUpgradesList()
    └── coinBank -= 成本
```

## 4. 数据流

```
[ScriptableObject 定义层]
    HeroUpgradeType ("Trait")
    HeroUpgradeDefinition ("Giant")
        ├── levels[0] = { cost: 5, description: "..." }
        └── AbilityPrefab = GiantComponent.prefab

[序列化层]
    SerializableHeroUpgrade
        ├── name: "Giant"         ← 序列化时保存 def.name ✅ PreSave:105
        ├── definition: null      ← [NonSerialized]
        └── level: 0
            ↓ BinaryFormatter
[存档文件]
            ↓ BinaryFormatter.Deserialize
    SerializableHeroUpgrade
        ├── name: "Giant"
        └── definition ← ResourceList<HeroUpgradeDefinition>.Get(name) ✅ PostLoad:112

[运行时层]
    HeroDefinition
        ├── traitUpgrade → SerializableHeroUpgrade("Giant", 0)
        │   └── definition → HeroUpgradeDefinition("Giant")
        └── upgrades → [classUpgrade, skillUpgrade, itemUpgrade, traitUpgrade]
```
