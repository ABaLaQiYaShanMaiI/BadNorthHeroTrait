=== BadNorthTitan 1.2 编译说明 ===

当前环境编译失败原因：
  本机仅安装了 .NET 11 Preview SDK，缺少 .NET Framework 4.8 目标包（Developer Pack）。
  BadNorthTitan.csproj 的目标框架为 net48（Unity游戏模组），需要 .NET Framework 4.8 SDK。

解决方法（任选其一）：

方法1 — 安装 .NET Framework 4.8 Developer Pack:
  下载地址：https://aka.ms/msbuild/developerpacks
  选择 ".NET Framework 4.8 Developer Pack" 安装后重启终端即可。

方法2 — 使用 Visual Studio 2022:
  如果安装了 VS2022（带 .NET 桌面开发工作负载），
  用 VS2022 打开 BadNorthTitan.csproj 或在 Developer Command Prompt 中执行：
    MSBuild BadNorthTitan1.2\BadNorthTitan.csproj -t:Build -p:Configuration=Debug

方法3 — 修改 csproj 目标框架（不推荐）:
  将 TargetFrameworkVersion 从 v4.8 改为 net48，
  但这需要确保引用的 BepInEx/Harmony/Assembly-CSharp 等都匹配。
